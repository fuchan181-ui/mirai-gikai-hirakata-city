- **ベースリポジトリ**: 沼津市版（`upstream-numazu/develop`）

## 1. 概要と目的

本設計書は、本家「みらい議会（国会向け）」および先行フォーク「沼津市版（みらい議会＠沼津市）」をベースとし、**大阪府枚方市議会向け**の地域版「**みらい議会＠枚方市**」を構築するための移行設計書である。

本家が定める [FORK_GUIDELINES.md](../../FORK_GUIDELINES.md)（AGPL-3.0 第7条に基づく追加条件）を完全に遵守し、中立・非公式の市民向けプラットフォームとして、枚方市民にとって親しみやすく、わかりやすい議会情報ポータルを実現する。

## 4. シードデータの構成案

枚方市議会の実際の議会構成・委員会構成・議案を反映したシードデータを定義する。

### 4.1 定例会（`council_sessions`）
- **定例月議会**: 枚方市議会は年4回（3月・6月・9月・12月）に定例月議会を開催。
- **設定案**:
  - `令和8年 第3回定例月議会（9月）`（Active, slug: `r8-9`）
  - `令和8年 第2回定例月議会（6月）`（slug: `r8-6`）

### 4.2 常任委員会（4委員会）
枚方市議会の委員会条例に基づく4常任委員会を設定する。
1. **総務常任委員会**（総合政策、危機管理、財務、総務、DX推進など）
2. **教育子育て常任委員会**（学校教育、子育て支援、保育、青少年育成など）
3. **市民福祉常任委員会**（健康増進、地域福祉、介護、市民生活、環境衛生など）
4. **建設環境常任委員会**（都市整備、土木建築、上下水道、公園河川、交通など）

### 4.3 会派構成（8会派）
枚方市議会に存在する代表的な会派構成案：
1. **大阪維新の会枚方市議会議員団**
2. **公明党議員団**
3. **自由民主党・無所属の会**
4. **連合市民の会**
5. **日本共産党枚方市会議員団**
6. **日本維新の会**
7. **命を守る政治**
8. **無所属**

### 4.4 議案サンプル（5件）
市民の関心が高く、論点が明確な議案サンプル：
1. `枚方市子ども医療費助成の対象拡充に関する条例改正案`（可決 / 福祉・子育て）
2. `枚方市駅周辺再整備基本計画の推進に関する補正予算案`（継続審議 / 都市計画・交通）
3. `地域包括ケアシステムの推進および在宅医療支援条例案`（可決 / 医療・福祉）
4. `市立小中学校における学校給食の充実に関する決議案`（否決 / 教育・学校）
5. `防災・減災まちづくり基本条例案`（審議中 / 防災・安全）

## 6. 免責文言・ライセンス遵守の整理

### 6.1 AGPL-3.0 および FORK_GUIDELINES の遵守方針
1. **サービス名称の義務付け**:
   - 必ず「**みらい議会＠枚方市**」の表記を使用する（「みらい議会」単独の商標的使用は避ける）。
2. **商標・ロゴの完全分離**:
   - 政党チームみらいのロゴ、タイポグラフィ、アイデンティティは一切使用しない。
   - 独自のロゴ（枚方市モチーフ）を配置する。
3. **免責文言の掲示**:
   - 全ページのフッターに以下の免責文言を常時表示する。
     > 「これは政党チームみらいが運営しているものではありません。」
     > 「本サービスはみらい議会を枚方市議会向けに改変した、有志による非公式サービスです。」
4. **ソースコード公開義務（AGPL-3.0）**:
   - ネットワーク経由で利用する全ユーザーに対し、改変部分を含む完全な対応ソースコードを提供できるよう、フッターから GitHub リポジトリ（`https://github.com/fuchan181-ui/mirai-gikai-fukuoka-city`）へ直接リンクを設置する。

## 7. テーマカラー（薄いピンク基調）の適用方針

「やさしい薄いピンク基調」を実現しつつ、行政情報サイトとしての可読性（WCAG 2.1 AAコントラスト比 4.5:1以上）を維持するカラーパレットを定義する。

### 7.1 カラーパレット設計

| 役割 | トークン名 | 沼津市版（青系） | 枚方市版（やさしいピンク系案） | 用途・選定理由 |
| :-- | :-- | :-- | :-- | :-- |
| **Primary** | `--primary` | `#1b6ca8` | **`#cf5678`** | ボタン、主要アクション（白文字とのコントラスト比 4.5:1以上を確保） |
| **Primary Accent** | `--primary-accent` | `#14507c` | **`#a83e5c`** | ホバー時、押下時、濃い強調テキスト |
| **Light Gradient Start** | `--color-mirai-gradient-start` | `#5aa9d6` | **`#f4a8b9`** | ヘッダーやフッターのグラデーション上部（桜色） |
| **Light Gradient End** | `--color-mirai-gradient-end` | `#cfe4f2` | **`#fcecee`** | グラデーション下部（ほんのり薄いピンク白） |
| **Surface Accent** | `--color-mirai-surface-accent` | `#e8f1f8` | **`#fdf2f4`** | ピックアップ枠、カードの強調背景 |
| **Pill Gradient Start** | `--color-mirai-light-gradient-start`| `#e3eef7` | **`#fae1e6`** | ピル・チップの背景グラデーション始点 |
| **Pill Gradient End** | `--color-mirai-light-gradient-end`  | `#f3f0e7` | **`#fdf8f5`** | ピル・チップの背景グラデーション終点 |
| **Background (Body)** | `--background` | `#f7f4ee` | **`#fbf8f7`** | サイト全体の基本背景（わずかに温かみのある桜白） |
